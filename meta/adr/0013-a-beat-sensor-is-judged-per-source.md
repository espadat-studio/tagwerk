# A beat sensor is judged per source, against its wiring

`doctor` keyed its sensor rows on an event's `ev` field alone, so one `beat` row stood for every agent at once. A machine running both wirings appends from two sources — 637 `claude` beats against 221 `pi` beats in one month here — and either count alone holds the row `live`, so a Claude hook that stops firing stays invisible for as long as the pi extension keeps beating. The row is now one per agent, built from `AGENTS` alongside the wiring checks `doctor` already ran: `last_seen` keys a beat as `beat:<src>`, and a source whose wiring does not read `wired` is measured against nothing and reads `unknown`. `CONTEXT.md` already promised both halves — **Dark** is silence "more likely a wiring fault than a true absence of signal", and a **missing** piece "explains a dark sensor; it is never an alarm of its own" — and the code asserted the first without ever consulting the second.

Rejected: a hardcoded row per known agent, which needs no wiring lookup and keeps the whole sensor list in one readable tuple, but reads `beat pi` dark for good on a machine that deliberately runs only Claude Code, which is the false failure **Unknown** exists to refuse. Rejected: deriving the rows from the sources already present in the ledger, which self-configures and cannot false-alarm, but leaves a hook that never once fired with no row at all — and a hook that never fired is the install fault `doctor` is most often run to find.

Consequences: `cmd_doctor` computes the wiring before the sensors, because the sensor verdicts now depend on it, though the wiring block still prints second. `doctor` prints four rows where it printed three, and the `beat` row name gained its source. An unwired agent contributes no darkness and so cannot reach exit 2 alone, which retires the ceiling `docs/troubleshooting.md` recorded and its advice to raise `sensor_dark_h` to silence the row. The Claude check still reads `~/.claude/settings.json` only, so a hook wired in a project's own settings reads `missing` and its beats go unjudged rather than dark. A beat carrying no `src` now raises instead of folding into an untagged row, which is safe because every beat `cmd_beat` has ever written carries one.
